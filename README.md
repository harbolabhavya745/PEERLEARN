# PeerLearn

PeerLearn is a collaborative learning platform where students can:

- connect with peers
- join study groups
- take AI-powered quizzes
- customize profiles
- chat and video call

## Features

- Responsive UI
- Dark Mode
- AI Quiz Engine
- Peer Chat
- Video Calling
- Gamified XP System

## Tech Stack

- HTML
- CSS
- JavaScript
